# Harish Karanam — Personal Portfolio

## Run locally
Open `index.html` in a browser.

## Customize
- Replace `assets/profile-photo.jpg` and `assets/linkedin-banner.jpg` with higher-resolution originals if available.
- Update the About, Current Focus, and Skills sections in `index.html`.
- Update the LinkedIn URL wherever needed.

## Safety note
The public portfolio intentionally does not display the phone number or email visible in the supplied LinkedIn screenshot. LinkedIn is used as the primary contact channel.
